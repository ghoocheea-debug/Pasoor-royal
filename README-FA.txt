پاسور رویال - پروژه اندروید نسخه آزمایشی

این پروژه یک پوسته اندرویدی ساده است که بازی HTML موجود را به صورت آفلاین در WebView باز می‌کند.
این فایل APK آماده نیست؛ برای ساخت APK باید پروژه را با GitHub Actions بسازید.

مراحل با گوشی:
1) یک حساب GitHub داشته باشید و وارد github.com شوید.
2) یک مخزن جدید (New repository) بسازید.
3) فایل ZIP پروژه را از حالت فشرده خارج کنید و تمام پوشه‌ها و فایل‌های داخل آن را در مخزن بارگذاری کنید.
4) در مخزن وارد Actions شوید و در صورت درخواست، گزینه فعال‌سازی Actions را بزنید.
5) از فهرست workflowها، گزینه Build Android APK را انتخاب کنید.
6) روی Run workflow بزنید و منتظر سبز شدن اجرا بمانید.
7) وارد اجرای موفق شوید؛ پایین صفحه در بخش Artifacts فایل Pasoor-Royal-debug-apk را دانلود کنید.
8) ZIP دانلودشده را باز کنید و app-debug.apk را نصب کنید. ممکن است اندروید اجازه نصب از همان مرورگر/فایل‌منیجر را بخواهد.

نکته‌ها:
- این APK آزمایشی و debug است، نه نسخه انتشار فروشگاهی.
- بازی داخل آن همان نمونه اولیه حکم است؛ بازی‌های دیگر، حکم دونفره و ارتباط بلوتوث/وای‌فای هنوز ساخته نشده‌اند.
- برای نصب، در تنظیمات اندروید فقط به برنامه‌ای که فایل APK را باز می‌کند اجازه نصب از این منبع بدهید؛ پس از نصب می‌توانید این اجازه را دوباره خاموش کنید.
